# Ciclo & cuidado

Aplicativo estático e mobile-first de acompanhamento de ciclo e sintomas. Não usa servidor de aplicação, banco de dados ou conta; os registros ficam no `localStorage` do navegador em uso.

## Publicação no GitHub Pages

Este repositório publica a pasta raiz pelo GitHub Pages. O conteúdo do repositório e o site são públicos. A página inclui metadado `noindex`, mas isso apenas solicita aos buscadores que não a indexem; não restringe o acesso.

## Dados e backups

Os dados são locais ao navegador e à origem do site. Não há sincronização automática e não são enviados ao GitHub pelo aplicativo. Para migrar do endereço Manus ou guardar uma cópia, use **Baixar meus dados** no site antigo. No novo endereço, escolha **Importar backup** e selecione o arquivo JSON. A importação substitui os registros locais atuais após uma confirmação. Guarde uma cópia do arquivo JSON em local protegido.

## Arquivos

- `index.html`: aplicativo, estilos e lógica no mesmo arquivo.
- `flower-logo.svg`: ícone floral.
- `robots.txt`: política para robôs de busca.
- `LEIA-ME.txt`: instruções adicionais em português.
